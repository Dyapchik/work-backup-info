Private desktop backup

Work Backup

Work Backup is a private backup setup operated by its account owner on a Linux computer. It uses rclone to back up Microsoft Word documents to a selected folder in the owner's Google Drive.

What it does

The backup uploads DOC, DOCX and DOCM files from a selected local folder, preserves previous versions of replaced files, and checks backup integrity. Temporary editor files and other document formats are excluded.

It uses Google Drive access to inspect the destination folder and maintain backup files. The owner's backup configuration limits operations to the selected folder, although the OAuth permission grants broader Drive access.

This website provides information only. It does not accept documents, credentials or Google sign-ins, and it does not run the backup. The setup is for its account owner's use and is not an online service offered to other users.
